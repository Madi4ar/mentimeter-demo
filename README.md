# Викторина

Живая викторина в стиле Mentimeter. Ведущий показывает вопросы на большом экране, участники отвечают с телефонов. Баллы зависят от скорости: верный ответ сразу даёт 10 баллов, верный в последнюю секунду даёт 1, неверный или без ответа даёт 0.

Интерфейс двуязычный: қазақша и по-русски. Переключатель «ҚАЗ | РУС» есть на экране ведущего (внизу справа) и на телефоне участника (вверху). Вопросы викторины вводятся на любом языке, они не переводятся автоматически.

## Запуск на Vercel (всё в облаке, ссылка постоянная)

Vercel не держит сервер «включённым», поэтому в этой версии состояние игры лежит в бесплатной базе Redis (Upstash), а телефоны и экран ведущего опрашивают `/api/state` раз в 1–2 секунды. Локальные `START.bat` / `server.js` продолжают работать как раньше.

1. Загрузите папку на GitHub (репозиторий можно сделать приватным) и на https://vercel.com нажмите **Add New → Project**, выберите репозиторий. Настройки сборки менять не нужно.
2. В проекте откройте **Storage → Create Database → Upstash for Redis** (Marketplace), бесплатный план, регион ближе к вашим участникам (например, Frankfurt). Нажмите **Connect Project**: переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами. Подойдёт и **Redis** (Redis Cloud): он добавляет `REDIS_URL`, код понимает и его.
3. **Settings → Environment Variables**: добавьте `HOST_PIN` = ваш PIN для ведущего (по умолчанию 1234, обязательно смените).
4. **Deployments → Redeploy** (чтобы переменные подхватились).
5. Участники открывают `https://ваш-проект.vercel.app`, ведущий — `https://ваш-проект.vercel.app/host`. QR-код на экране ведущего уже ведёт на нужный адрес. Мобильный интернет работает без туннелей.

Заметки:
- Бесплатный Upstash даёт около 500 000 команд в месяц. Один участник за вопрос делает ~5–15 запросов опроса, так что для 50–100 человек и 15 вопросов лимита с запасом хватает. Для больших залов возьмите платный план.
- Перед новой игрой нажмите «Сбросить» в панели ведущего.
- Время ответа и очки считает сервер, поэтому задержка сети слегка влияет на баллы (доли секунды).

## Запуск одной кнопкой (Windows)

Дважды щёлкните по файлу `START.bat`. Он сам:
- придумывает случайный PIN (каждый раз новый),
- запускает сервер,
- при первом запуске скачивает `cloudflared` и создаёт публичную ссылку,
- открывает экран ведущего в браузере уже со входом по PIN.

В окне будут показаны ссылка для участников и PIN, они же сохраняются в файле `ПОСЛЕДНЯЯ_ССЫЛКА.txt`. Не закрывайте чёрное окно во время игры, для остановки нажмите Enter. Нужен только установленный Node.js. Ссылка меняется при каждом запуске.

Если Windows или антивирус спрашивает разрешение для `cloudflared.exe` или `node.exe`, разрешите. Ручной способ описан ниже.

## Запуск на своём компьютере

Нужен Node.js 16 или новее. Больше ничего устанавливать не надо.

```
HOST_PIN=мойпин node server.js
```

На Windows (PowerShell):

```
$env:HOST_PIN="мойпин"; node server.js
```

- Экран ведущего: `http://localhost:3000/host`, затем введите PIN. Откройте его на ноутбуке, который подключён к проектору.
- Участники: QR-код и адрес показываются на экране ведущего. Телефоны должны быть в одной Wi-Fi сети с компьютером.
- Если Wi-Fi в зале не пускает устройства друг к другу, запустите сервер на хостинге (ниже).

## Как проводить

1. Откройте `/host`, в «Редакторе вопросов» введите вопросы. Для каждого отметьте «Верный» и задайте время на ответ. Вариантов ответа может быть от 2 до 8 (кнопка «+ Вариант»), они подписываются A), B), C)… Длинные вопросы и ответы (до 1000 и 400 символов) на экране автоматически уменьшаются, чтобы поместиться. Можно вставить все вопросы списком: вопросы разделены пустой строкой, перед верным ответом ставится «+».
2. Перейдите в зал ожидания. Участники сканируют QR-код и вводят имя и фамилию.
3. Нажмите «Начать игру». Дальше всё делается пробелом: показать ответ, рейтинг, следующий вопрос. Ответ показывается сам, когда истекло время или ответили все подключённые.
4. Рейтинг можно показывать после любого вопроса, например в середине игры. В конце кнопка «Итоги» показывает подиум.

Вопросы сохраняются в `data/quiz.json`. Ход игры и очки хранятся в памяти: после перезапуска сервера игра начинается заново.

## Участники с мобильным интернетом (Windows)

Телефоны на мобильном интернете не видят ваш компьютер, поэтому нужен публичный адрес. Самый простой способ не требует регистрации.

1. Запустите сервер, как описано выше (`set HOST_PIN=5555`, затем `node server.js`) и не закрывайте это окно.
2. Скачайте `cloudflared-windows-amd64.exe` со страницы https://github.com/cloudflare/cloudflared/releases/latest и положите в папку `viktorina`.
3. Откройте вторую командную строку в этой папке (в адресной строке папки введите `cmd`) и выполните:
   `cloudflared-windows-amd64.exe tunnel --url http://localhost:3000`
4. В окне появится адрес вида `https://что-то-там.trycloudflare.com`. Откройте в браузере этот адрес с добавлением `/host`, например `https://что-то-там.trycloudflare.com/host`, и введите PIN.
5. На экране зала ожидания QR-код уже ведёт на публичный адрес. Участники сканируют его с мобильным интернетом.

Адрес меняется при каждом запуске туннеля. Оба окна должны оставаться открытыми всю игру. Сервис сам переключается на опрос раз в секунду, если туннель не пропускает потоковую связь, это нормально. Бесплатный туннель подходит для небольших мероприятий, перед игрой обязательно сделайте пробный запуск с 2–3 телефонами на мобильном интернете.

Для постоянного адреса выложите папку на хостинг (Render, Railway, Fly.io): команда запуска `node server.js`, переменная `HOST_PIN`. Порт хостинг задаёт сам. На бесплатных тарифах диск часто стирается при перезапуске, поэтому вводите вопросы незадолго до игры.

## Қазақша қысқаша: неге мобильді интернетпен қосылмайды?

QR-кодта компьютердің Wi-Fi мекенжайы (мысалы `192.168.x.x`) тұр. Бұл мекенжай тек сол Wi-Fi ішінде жұмыс істейді, мобильді интернеттегі телефон оны көре алмайды. Шешімі: жоғарыдағы cloudflared туннелін қосып, `https://...trycloudflare.com/host` арқылы кіру. Сонда QR-код ашық мекенжайға көрсетеді. Туннельсіз зал ішіндегі Wi-Fi-ды қолдануға болады.

## Настройки

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | 3000 | порт сервера |
| `HOST_PIN` | 1234 | PIN для входа на экран ведущего. Обязательно смените |
| `PUBLIC_URL` | пусто | необязательно: адрес для QR-кода. Если открывать `/host` по публичному адресу, он подставляется сам |
| `DATA_DIR` | `./data` | куда сохранять вопросы |

## Стили (Tailwind CSS)

Интерфейс написан на чистом JavaScript (без фреймворков) и стилизован Tailwind CSS v4. Готовый `public/tailwind.css` уже собран и лежит в архиве, поэтому для запуска ничего устанавливать не нужно. Если вы меняете классы в `public/host.html`, `public/index.html`, `public/ui.js` или `public/i18n.js`, пересоберите стили:

```
npm install
npm run build:css
```

Цвета, шрифты и анимации описаны в `src/tailwind.css` (блок `@theme`).

Шрифты Exo 2, Golos Text и IBM Plex Mono (лицензия SIL OFL) и библиотека qrcode-generator (MIT) лежат в папке `public`, интернет для их загрузки не нужен.
